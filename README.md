# WeSpark Listening · Desktop Preview

Public desktop UI prototype for WeSpark Listening.

- [Open the demo](https://tai221.github.io/wespark-listening-glass-preview/)
- [Dictation — five sentences](https://tai221.github.io/wespark-listening-glass-preview/dictation.html)
- [Shadowing](https://tai221.github.io/wespark-listening-glass-preview/shadowing.html)
- [Conversation](https://tai221.github.io/wespark-listening-glass-preview/conversation.html)

Updated 2026-11-03: conversation review now includes pronunciation, session-wide
CEFR vocabulary statistics, inline grammar corrections, average speech speed,
and three intonation views. Added task/context sidebar, per-question hints,
completed-session replay and review navigation.

Previous update 2026-11-02: aligned practice controls, direct Shadowing flow with word-level
feedback and dictionary popups, one-time SparkPoint rewards, and a standalone
Dictation completion page with reward transfer to the header wallet.
Dictation uses five sentences, with review and replay preserving earned points.

Desktop web only. Reference audio is synthetic. Conversation can record microphone
audio locally after browser permission, with per-turn replay while the page remains
open. Recordings are not uploaded or retained after refresh. Transcripts, feedback,
CEFR labels and speech-analysis metrics are scripted UI fixtures. Progress and
illustrative SparkPoint stay in the browser tab; there is no connected account,
backend or AI grading service.
Only Listening is published; navigation to other product areas is unavailable.

Only browser runtime assets are published. Internal plans, research, credentials,
QA scripts, source artwork and verification logs are excluded.
