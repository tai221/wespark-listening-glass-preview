Public desktop UI prototype for WeSpark Listening.

Updated 2026-11-05: compact conversation introduction with reading-paced reveals,
three goals and a final “Nói thử ngay!” launch. Refreshed preparation, practice
choices and desktop lesson navigation; shared sound controls and raised buttons.
Conversation review includes pronunciation, vocabulary, grammar, fluency and intonation.

Desktop web only. Learner recordings stay in the browser tab where supported;
conversation replies and feedback are scripted demo data, not AI grading.
Lesson audio uses synthetic speech. Progress and illustrative SparkPoint stay
in the browser; there is no connected account or backend.
Listening and Speaking are published; other product areas are unavailable.

Only browser runtime assets are published. Internal plans, research, credentials,
QA scripts, source artwork and verification logs are excluded.
